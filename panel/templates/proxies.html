{% set configured = accounts|selectattr('proxy')|list|length %}

Место под пул прокси готово: файл proxies.txt рядом с config.txt, строка — «аккаунт;прокси». Настроено сейчас: {{ configured }} из {{ accounts|length }}{% if configured < accounts|length %}, остальные идут напрямую или через прокси из config.txt{% endif %}.

Как подключить (когда прокси появятся)

  1. Скопируйте proxies.example.txt в proxies.txt.
  2. Впишите по строке на аккаунт: sender1;socks5://логин:пароль@хост:порт.
  3. Перезапустите панель и воркер — они подхватят файл при старте.
  4. Проверьте: python diagnose.py покажет, через какой прокси идёт каждый аккаунт.

Почему это важно. Telegram связывает аккаунты по IP: если с одного адреса идут сообщения с нескольких аккаунтов, при жалобах блокируют всю группу. Поэтому правильный пул — один прокси на аккаунт, желательно в разных подсетях.

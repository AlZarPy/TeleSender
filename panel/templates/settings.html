Как это работает

Панель: http://{{ lan_ip }}:{{ port }} · пароль в .env → PANEL_PASSWORD.

Проверка канала: python diagnose.py · журнал отправок: sent.jsonl и база панели.

Воркер: python -m panel.worker (или run_worker.cmd) — без него кампании стоят на месте.

Ответы: python -m panel.replies — помечает тех, кто ответил, чтобы им можно было писать снова.

Сторож: {{ thresholds }}

Прогрев подписками: список каналов в warmup_channels.txt, до 3 подписок в сутки в дни прогрева.

Сводка за сутки приходит в «Избранное» Telegram после 10:00; там же тревоги сторожа и флуда.

Правила, которые снижают жалобы: не больше 10 сообщений в час с аккаунта, паузы 25–70 секунд, разные варианты текста, обращение по имени, никому не писать дважды, кроме тех, кто ответил.

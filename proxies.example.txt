# Прокси для аккаунтов — отдельно от config.txt (там api_hash, его лучше не трогать).
#
# Формат: аккаунт;прокси   — по одной строке на аккаунт.
# «аккаунт» — это session_name из config.txt (например, sender1).
# Если аккаунт здесь не указан, берётся прокси из config.txt.
# Строка из этого файла главнее: удобно менять прокси, не редактируя ключи.
#
# Поддерживаются схемы:
#   socks5://ЛОГИН:ПАРОЛЬ@ХОСТ:ПОРТ
#   socks5://ХОСТ:ПОРТ
#   http://ЛОГИН:ПАРОЛЬ@ХОСТ:ПОРТ
#   mtproxy://ХОСТ:ПОРТ:СЕКРЕТ
#
# Правило для бригады: один аккаунт — один прокси (лучше — свой IP).
# Два аккаунта через один прокси связываются между собой при жалобах.
#
# Пример (уберите # в начале строки, когда прокси появятся):
# sender1;socks5://user:pass@45.130.124.195:8000
# sender2;socks5://user:pass@196.19.9.164:443
# sender3;mtproxy://196.19.9.164:443:0123456789abcdef0123456789abcdef

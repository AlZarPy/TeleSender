# Промт для презентации TheПечкин / «Почтамт»

Скопируйте блок целиком в ChatGPT / Claude / Gamma / Beautiful.ai.
В нём зашиты: бренд, словарь фирменных названий, факты о продукте, структура слайдов,
стиль, вау-элементы и запреты. Модель не должна выдумывать цифры — только брать из блока ФАКТЫ.

═══════════ КЛЮЧЕВАЯ ОСОБЕННОСТЬ: ПРИСКАЗКА ═══════════

Каждая записка начинается с фирменной формулы:

    «Я почтальон Печкин, принёс записку для <Имя> …»

Зачем это нужно (использовать как главный смысловой аргумент):
• получатель с первых слов понимает, кто пишет и почему именно ему;
• это не безликая рассылка, а адресное обращение: имя подставляется автоматически;
• формула задаёт вежливую рамку — дальше идёт короткая записка: суть, просьба, подпись;
• единый голос бренда: получатель узнаёт TheПечкин по первым пяти словам.

Присказка настраивается: полная («Я почтальон Печкин, принёс записку для <Имя>»),
короткая («Печкин, записка для <Имя>») или без неё — для баз, где отправитель известен.
Названия вариантов в интерфейсе: «полная присказка», «короткая», «без присказки».

Честность: присказка делает сообщение понятным, но не делает его законным. Массовая
рассылка незнакомым нарушает правила Telegram — риск лежит на владельце аккаунтов.

═══════════ ФАКТЫ (использовать ТОЛЬКО их) ═══════════

Транспорт и архитектура:
• MTProto через Telethon — обычный пользовательский аккаунт, не Bot API.
• Бригада: 10–30 почтальонов, у каждого свой прокси (SOCKS5 или MTProxy).
• Сумка: ориентир 15–20 записок в сутки для нового аккаунта, 30–50 для прогретого.
• Ротация: следующая записка уходит через почтальона с самой полной сумкой.
• Привал: FloodWait от Telegram → аккаунт отдыхает указанное время, а получатель
  остаётся в маршруте и уходит через другого почтальона. Никто не теряется.
• Походка: паузы 25–70 секунд со случайным разбросом; приёмные часы задаются (например 9–21).
• Квитанции: каждая отправка фиксируется с результатом и отметкой на конверте:
  «адрес не найден», «дверь не открыли» (privacy), «заколочено» (forbidden), «себе», «ДТП» (прочие ошибки).
• Повторный запуск не дублирует: получатели с квитанцией о доставке пропускаются.
• Разведка дороги: отдельная проверка доступности дата-центров Telegram — отличает
  блокировку сети от троттлинга и от ошибки в коде.
• Удостоверения: вход по коду или QR; файлы сессий не попадают в репозиторий.
• Тесты: 40 проверок без сети + 7 на фейковом клиенте (flood / privacy / not_found / self).
• Всё локально на своём железе: без подписки, без облака, данные не уходят третьим лицам.

Стек по слоям:
• транспорт — Python 3 + Telethon (MTProto), SOCKS5/MTProxy;
• движок — воркер: маршрут, бригада, сумки, привал, сторож;
• данные — SQLite: обходы, получатели, квитанции, события;
• интерфейс — FastAPI + Jinja2 + адаптивный CSS (десктоп и телефон);
• CLI-режим — те же модули без панели, для cron и отладки.

Задачи инструментов:
• движок — доставляет записки, держит походку, не теряет получателей при сбоях;
• панель «Почтамт» — делает состояние видимым: кто получил, кто нет и почему;
• разведка дороги — отвечает на вопрос «это блокировка или мой код»;
• квитанции — дают воспроизводимость: по любой записке видно почтальона, время, причину.

Опционал (помечай честно: «работает» или «в планах»):
• почерки — несколько вариантов формулировки, чтобы тексты не совпадали дословно;
• пробный обход — предпросмотр пяти записок без отправки;
• сторож — авто-стоп обхода при серии отметок на конверте;
• обратная почта — ответивший помечается «ответил» и исключается из маршрута;
• прикидка маршрута — «200 получателей × сумка 20 = 10 дней»;
• телеграмма — сводка о завершении обхода в Telegram;
• штемпели — теги получателей, возврат отправителю, опись и разгрузить мешок.

Чего сервис НЕ делает (говорить прямо):
• не парсит участников групп и не занимается инвайтингом;
• не обходит лимиты Telegram — наоборот, уважает их;
• не гарантирует доставку и не спорит с правилами платформы.

| Инструмент | Что вставить | Результат |

Дополнительные строки по вкусу:
- `Сделай версию для инвестора: замени слайд 13 на юнит-экономику, добавь слайд «почему локально дешевле SaaS».`
- `Сделай английскую версию, сохранив названия брендов без перевода.`
- `Сгенерируй текст присказки в трёх вариантах для разных аудиторий.`

## Что важно не потерять при правках

1. **Присказка** — не украшение, а смысл бренда: она объясняет получателю, кто и зачем пишет.
2. **Словарь** — если названия поедут в презентации, они поедут и в интерфейсе; лучше сразу держать один язык.
3. **Честность** — риск-радар и запреты делают деку убедительнее для скептиков, чем любые обещания.

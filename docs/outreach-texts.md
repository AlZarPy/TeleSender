# Тексты рассылки · Школа взрывного роста AI (Терра)

Правила: первое касание — без ссылок, 3–5 строк; ссылка уходит в ответ.
Спинтаксис `{а|б}` панель превращает в варианты, `<ЕгоИмя>` подставляет имя получателя.

## Вариант 1 — «открытие»

```
{Здравствуйте|Добрый день}, <ЕгоИмя>! Меня зовут {Алексей|Мария}, я куратор
Школы взрывного роста AI, {сообщества предпринимателей|бизнес-клуба|образовательной
платформы для предпринимателей} «Терра».

13 ноября, 15:00, Конгресс-центр ЦМТ, 4-й подъезд, Москва,
Краснопресненская наб., 12 — {стартует|открывается} 41-й поток: {бесплатное|без оплаты}
обучение для предпринимателей. Упор на ИИ: продажи, маркетинг, автоматизация.

{Рассказать подробнее?|Интересно, что там по программе?}
```

## Вариант 2 — «короткий вопрос»

```
<ЕгоИмя>, {здравствуйте|привет}! {Это|На связи} {Алексей|Мария}, куратор Школы
взрывного роста AI — {сообщества предпринимателей|бизнес-клуба|образовательной
платформы для предпринимателей} «Терра».

{13 ноября|13-го числа}, 15:00, Конгресс-центр ЦМТ, 4-й подъезд,
Москва, Краснопресненская наб., 12 — открытие нового потока, вход {бесплатный|без оплаты}.
Упор на ИИ в бизнесе: продажи, маркетинг, автоматизация.

{Прислать программу?|Скинуть подробности?}
```

## Ответ тем, кто откликнулся (уже со ссылкой)

```
Отправляю, <ЕгоИмя>!

«Терра» — {сообщество предпринимателей|бизнес-клуб|образовательная платформа
для предпринимателей}. 13 ноября, 15:00 — Конгресс-центр ЦМТ, 4-й подъезд,
Москва, Краснопресненская наб., 12. Участие бесплатное, по регистрации:
{ссылка аккаунта}

Группа школы, где выкладывают программу и расписание: {ссылка}
```

## Что не делать в первом сообщении

- не больше одной ссылки, лучше ноль;
- без «уважаемый предприниматель», «специальное предложение», «не упустите шанс»;
- не больше одного эмодзи, лучше ни одного;
- не отправлять одинаковый текст с разных аккаунтов — использовать варианты.

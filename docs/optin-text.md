# Opt-in тексты — только тем, кто дал контакт

Смысл: сообщение уходит человеку, который сам оставил контакт (заявка на сайте,
регистрация на прошлом потоке, участник группы школы). Тогда согласие есть по факту,
и статья 18 закона «О рекламе» соблюдена.

## Текст 1 — узнавание и напоминание (первое касание, без продажи)

```
{Здравствуйте|Добрый день}, <ЕгоИмя>!

Это <МоёИмя>, куратор Школы взрывного роста AI. Вы {оставляли заявку|регистрировались|были у нас} на «Терре» — пишу по этому контакту, чтобы не потерялись.

13 ноября, 15:00, Конгресс-центр ЦМТ (Москва, Краснопресненская наб., 12, 4-й подъезд) — открытие 41-го потока. Участие бесплатное.

{Рассказать, что будет в программе|Прислать программу}|{Рассказать, что будет в программе|Прислать программу}
```

## Текст 2 — программа и ссылка (после ответа или для тёплых)

```
<ЕгоИмя>, как обещал — коротко о дне.

13 ноября, 15:00, Конгресс-центр ЦМТ, Москва, Краснопресненская наб., 12, 4-й подъезд. Открытие 41-го потока школы «Терра».

программа дня: четыре направления — vibe coding, нейропродавец, контент-завод, ИИ-ассистент.

Программа и регистрация: https://zapuskterra.ru/

Кому передать приглашение — скажите имя, отправлю.
```

## Текст 3 — отписка (обязательный, в каждом сообщении)

Добавляется последней строкой в любой из текстов выше:

```
Если неактуально — напишите «стоп», больше писать не буду.
```

## Правила, которые нельзя нарушать

| Правило | Почему |
|---|---|
| Пишем только тем, у кого `consent=1` в базе | иначе это холодное первое касание, и opt-in-логика теряется |
| «стоп» обрабатывается в один шаг | `followup` уже ставит `block_recipient`, повторно не пишем никогда |
| Ссылка только во втором сообщении | первое касание без ссылки меньше похоже на рекламу и лучше доходит |
| Имя куратора — `<МоёИмя>`, никогда спинтаксисом | иначе аккаунт Алексея подписывается «Мария» |
| Текст не повторяется у разных аккаунтов | за это отвечает `panel/unique.py` |

## Что считается согласием

| Источник | Согласие есть | Чем подтверждается |
|---|---|---|
| Заявка на сайте с галочкой | да | запись в CRM, дата |
| Регистрация на прошлый поток | да | письмо с билетом |
| Участник группы школы | да, если правила группы это допускают | правила группы |
| Купленная база | **нет** | — |
| Участники чужого чата, выгрузка | **нет** | — |
| Знакомый, давший контакт лично | да | переписка |

# Оффер · первое сообщение и второе

## Логика оффера

Задача первого сообщения — не продать мероприятие, а получить одно короткое действие:
человек называет свою нишу. Всё остальное он получает во втором сообщении.

Формула: **конкретный результат под его нишу** (3 сценария применения ИИ) +
**измеримая выгода** (5–10 часов в неделю) + **нулевой риск** (бесплатно) + **дедлайн** (13 ноября).

Почему работает лучше, чем «приходите на мероприятие»:
- спрашиваем, а не рекламируем — отвечать на вопрос легче, чем соглашаться на визит;
- отклик стоит одно слово («опт», «услуги ремонта»), барьер почти нулевой;
- обещан второй текст с конкретикой — это и есть причина ответить;
- ссылки нет — сообщение не похоже на рассылку.

## Первое сообщение

```
{Здравствуйте|Добрый день}, <ЕгоИмя>! {Это|На связи} <МоёИмя>, куратор
Школы взрывного роста AI, {сообщества предпринимателей|бизнес-клуба|образовательной
платформы для предпринимателей} «Терра».

13 ноября, 15:00, Конгресс-центр ЦМТ, 4-й подъезд, Москва,
Краснопресненская наб., 12 — открытие 41-го потока, участие бесплатное.

Предложение короткое: назовите {нишу|сферу} — пришлю 3 сценария, где ИИ в ней
забирает рутину и освобождает {5–10|6–8} часов в неделю. Без воды, с цифрами.

{Назвать нишу?|Какая у вас сфера?}
```

## Второе сообщение (после ответа)

```
<ЕгоИмя>, спасибо. Вот что даёт ИИ именно в {нише}:

1. {сценарий — что заменяет, сколько часов в неделю освобождает}
2. {сценарий}
3. {сценарий}

Ровно это разбирают 13 ноября в ЦМТ: 39 мастер-классов, школа «Нейросети»
(Илья Дрозд) и разборы с наставником — 3 месяца, группа 8–10 человек.
Вход бесплатный, по регистрации: {ссылка аккаунта}

{Подобрать вам мастер-классы под вашу задачу?|Скинуть расписание под вашу сферу?}
```

## Альтернативные офферы, если нужен другой тон

| Оффер | Первое сообщение | Кому |
|---|---|---|
| Список под нишу | «пришлю 3 мастер-класса из 39, которые дадут вам больше всего» | тем, кто уже ходил на конференции |
| Разбор цифр | «пришлю, как наставник разбирает юнит-экономику за 3 встречи» | собственникам с командой |
| Потери от рутины | «посчитаем, сколько часов в месяц у вас съедает ручное» | производство, услуги |
| Один инструмент | «пришлю 5 промптов, которые заменяют копирайтера на утро» | малый бизнес, маркетинг |
| Наставник | «3 месяца с предпринимателем-практиком, группа 8–10 человек» | тем, кто ищет окружение |

## Чего не делать

- не обещать созвон от имени наставника — это не наша зона;
- не писать «бесплатно» дважды в одном сообщении;
- не отправлять второе сообщение без ответа — там уже ссылка, вырастет риск жалобы;
- не использовать «гарантируем рост выручки».

# Промт для поиска прокси

## 1. Промт для поиска провайдеров

Скопировать целиком в поисковик с ИИ (Perplexity, ChatGPT с поиском, You.com):

```
Найди 5 провайдеров, у которых можно купить выделенные статические IPv4-прокси
в Португалии с протоколом SOCKS5.

Требования к товару:
- страна IP: Португалия (PT)
- тип: датацентр или ISP, НО обязательно выделенный (dedicated, «в одни руки»),
  один IP на одного клиента
- протокол: SOCKS5 (HTTP как дополнительный вариант допустим)
- статический IP: адрес не меняется в течение всего срока аренды
- срок аренды: от 3 дней до 1 месяца
- цена: до 2 долларов за IP на месяц (или до 0,5 доллара за IP на 3 дня)
- авторизация: по логину и паролю, не по IP-адресу
- количество: нужно 20 адресов, но начинать буду с 5

Что исключить: ротационные прокси, shared (до 2-3 пользователей на IP),
IPv6-only, MTProto (Telegram-only), мобильные дороже 3 долларов в сутки.

Для каждого провайдера дай таблицу со столбцами:
название | ссылка на страницу с ценами | тип прокси | протоколы | есть ли Португалия |
сроки аренды | цена за IP | минимальный заказ | способы оплаты из России |
упоминается ли ограничение на Telegram

В конце добавь: у кого из них дешевле всего 5 адресов на 3 дня и у кого — 20 адресов
на месяц. Приведи ссылки, а не пересказ.
```

## 2. Промт для проверки конкретного провайдера

```
Вот сайт провайдера прокси: <ссылка>.
Проверь по его страницам и правилам:
1. Есть ли в наличии IPv4 Португалия и сколько адресов.
2. Прокси выделенные или shared.
3. Поддерживается ли SOCKS5.
4. Какой минимальный срок и цена за 1 IP, за 5 IP, за 20 IP.
5. Есть ли в правилах (Terms, FAQ) запрет на Telegram, мессенджеры или массовые
   рассылки — процитируй формулировку.
6. Требуется ли привязка к IP или авторизация по логину и паролю.
Если чего-то нет на сайте — так и напиши «не указано», не додумывай.
```

## 3. Сообщение продавцу

```
Здравствуйте. Нужны выделенные статические IPv4-прокси Португалии, SOCKS5,
авторизация по логину и паролю, 20 адресов.

Критично: соединения к серверам Telegram (149.154.167.51:443, 149.154.175.53:443)
должны проходить, не блокируются ли они у вас?

Нужен тест: 5 адресов на 3 дня. Если Telegram проходит — беру 20 на месяц
и дальше на постоянку.
```

## 4. Как проверяю я (после покупки)

```
curl -x socks5://ЛОГИН:ПАРОЛЬ@ХОСТ:ПОРТ https://api.ipify.org
```
IP в ответе должен быть португальским — это проверка страны.

Дальше живой клиент: вход португальского аккаунта через этот прокси,
`get_me`, сообщение `@SpamBot`. Только это доказывает, что Telegram проходит:
`curl` к адресам Telegram даёт `000` и при рабочем прокси, потому что там MTProto,
а не HTTPS.

## 5. Красные флаги в ответе провайдера

| Что написано | Почему не годится |
|---|---|
| «ротация», «rotating», «каждый запрос новый IP» | Telegram-сессия умрёт |
| «shared», «до 3 пользователей» | аккаунты свяжутся через чужие |
| «IPv6 only» | наши клиенты идут по IPv4-адресам дата-центров |
| «MTProto» | секрет `ee`, Telethon не подключается |
| «Telegram не поддерживается» | ровно наша проблема |
| цена ниже $0,3 за IP в месяц | обычно это пул с плохой репутацией |

# Финальные два сообщения · 41-й поток

Версия собрана из двух источников: первое — вариант Claude Sonnet 5.5 (короче и живее),
второе — мой с добавленной концовкой про вопросы в чате. Спинтаксис внутри — чтобы
у каждого аккаунта был свой вариант текста (`panel/unique.py`).

## Первое — вовлекающее, без ссылки, 360–400 знаков

```
<ЕгоИмя>, {добрый день|здравствуйте}! Я <МоёИмя>, {куратор школы «Терра»|куратор Школы взрывного роста AI клуба «Терра»}.

13 ноября в Москве бесплатное открытие 41-го потока — подойдёт и тем, кто пока новичок. Разберём маркетинг, продажи, финансы и автоматизацию бизнеса.

Напишите «да», и я пришлю подробности. Вопросы по курсу можно задать прямо в этом чате.

Если не интересно — просто проигнорируйте, больше писать не буду.
```

## Второе — основное, с картинкой и ссылкой

```
{Рад, что откликнулись|Спасибо за ответ}! Открытие 41-го потока: 13 ноября, 15:00, Конгресс-центр ЦМТ, Москва, Краснопресненская наб., 12, 4-й подъезд.

Как записаться:
1. На входе вам выдадут браслет с инвайт-кодом.
2. Откройте приложение «Терра», раздел «Школа взрывного роста AI», и введите код.
3. Вступите в чат 41-го потока.

Участие бесплатное. Программа и регистрация: {{LINK}}

Если что-то неясно — пишите сюда, отвечу лично. Неактуально — напишите «стоп».
```

## Правила отправки

| Что | Значение |
|---|---|
| Интервал между сообщениями | не меньше 20 минут: второе идёт только после ответа |
| Ссылка | персональная инвайт-ссылка аккаунта, подставляется вместо `{{LINK}}` |
| Картинка | баннер «Начни применять AI в бизнесе бесплатно» — во втором сообщении |
| Кому второе не отправляем | тем, кто не ответил или ответил «нет» |
| Отписка | «стоп» в любом сообщении → `block_recipient`, больше не пишем |
